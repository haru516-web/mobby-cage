# コーデックス用プロンプト（アプリアイコン）

以下をそのままコーデックスに貼る。

---

最初に、`D:\ori-chara-ios` の worktree `D:\ori-chara-ios-codex`（ブランチ `codex/assets`）が無ければ、元のフォルダで `git worktree add ../ori-chara-ios-codex codex/assets` を実行して作成してください。あれば作り直さずそのまま使います。作業は D:\ori-chara-ios-codex だけで行い、最初に `git merge main` で main の最新を取り込んでください。main や他ブランチには触らず、push もしないでください。

アプリ「おりっこ」のアイコン候補を4案作ってください。コードは変更しないでください。

## アプリの内容
自分の好きな画像（キャラ・ペット・推しなど）を、かわいい檻に閉じ込めて、ホーム画面のウィジェットに置くアプリ。檻のデザインはパステル系、金属系、和風、宇宙など複数ある。名前は「おりっこ」。

## アイコンの条件（App Store 提出用）
- サイズは 1024×1024 の PNG。
- **背景は不透明**にする（アルファチャンネルなし。RGB の PNG として保存）。
- 角丸にしない（正方形のまま。角丸は iOS が自動でつける）。
- 文字・ロゴ・数字は入れない。
- 小さく表示されても（60px 程度）、檻だと一目で分かること。
- 重要な要素は中央の約80%の範囲に収める（端が切れても崩れないように）。

## デザインの方向
- モチーフ: **檻だけ**。キャラ・動物・シルエットなど、檻の中に何も入れない。檻の内側は背景の色やグラデーションが見える状態にする。
- 小さく表示されても分かるよう、檻はアイコンいっぱいに大きく、格子は太めで少なめ（縦棒4〜5本＋外枠）にする。
- 雰囲気: かわいい、やさしい、ポップ。アプリ内の背景（パステルのグラデーション）と揃える。暗すぎない配色にする。
- 檻は真正面から見た、平面的でシンプルな表現。立体感は軽いハイライト程度。
- 4案は方向を変える。
  1. パステルのグラデーション背景＋銀色の檻
  2. ピンク系の背景＋ハート飾りのついた檻
  3. 水色〜紫の背景＋星飾りのついた檻
  4. クリーム色の背景＋金の縁取りの檻

## ファイルと確認
- 保存先は `assets/icon_candidates/`。ファイル名は `icon_1.png` 〜 `icon_4.png`。
- 既存の `assets/icon.png` は**上書きしない**（こちらで選んで差し替える）。
- 4案を並べた確認用の画像 `assets/icon_candidates/preview.png` も作る。
- Pillow で、各 PNG が 1024×1024・RGB（アルファなし）であることを確認する。
- 4案をコミットして、確認結果（サイズ・モード）を報告する。
- 変更してよいのは `assets/icon_candidates/` 内のファイルだけ。
