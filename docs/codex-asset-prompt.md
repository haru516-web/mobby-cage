# コーデックス用プロンプト（背景・檻アセットの作成）

以下をそのままコーデックスに貼る。

---

あなたはこのリポジトリ（iOS ウィジェット中心のアプリ「檻キャラ」、Expo + SwiftUI）で、**画像アセットだけ**を作る担当です。コードは変更しないでください。

## アプリの概要
ユーザーが自分でアップした画像（背景透過の人物・キャラ・動物など）を「檻に閉じ込めた」ように見せる。描画は下から順に次の3枚を重ねるだけです。

1. 背景画像 `assets/bg.png`
2. ユーザーの画像（背景は透過。中央・下寄せで 幅80% / 高さ78%、下端は下から9%の位置）
3. 檻の透過PNG（ユーザーの画像より手前）

## いまの問題（作り直しの理由）
- 背景: 暗い紫の空っぽの部屋で、つまらない。床に遠近感があるのに、檻が真正面から見た平面なので違和感がある。
- 檻: 灰色で太い格子が7本あり、ユーザーの画像のど真ん中を縦に分断して見づらい。魅力もない。

## 作るもの（ファイル名・サイズは固定。既存ファイルを上書き）

### 1. `assets/bg.png` — 背景
- 1024×1024、不透明PNG。
- 真正面から見た、遠近感のない平面的なイラスト調。
- 明るくかわいい、またはおしゃれな雰囲気（パステル基調。ホーム画面で映える）。暗すぎない。
- 中央〜下寄りにユーザーの画像が立つので、中央は静かで低コントラストにして、どんな画像でも目立つようにする。
- 床や台座を描く場合は、画面の下から約9%の高さで、遠近のない水平な帯にする（画像の足元がここに乗る）。
- 小物・文字・ロゴ・人物は入れない。

### 2. `assets/cage_square.png` — 檻（正方形）
- 1024×1024、**背景透過のRGBA PNG**。
- 真正面から見た檻。キャンバス全体いっぱいに、枠と縦格子を描く。
- 格子は**細く、本数は少なめ**（縦棒4〜5本＋外枠）。檻が占める面積は全体の20%以下にして、閉じ込めた画像がしっかり見えること。
- 質感は光沢のある金属の丸棒（ハイライトと陰影つき）。かわいさのある、少しポップな仕上がり。
- **檻の内側は完全に透明**にする。檻の外側への影・背景・床は入れない。
- 縁のアルファはきれいにする（白や黒のフチが出ないこと）。

### 3. `assets/cage_wide.png` — 檻（横長）
- 1536×768（2:1）、背景透過のRGBA PNG。
- `cage_square.png` と同じデザインで、格子の間隔を保ったまま本数を増やす（縦棒8本前後＋外枠）。
- 他の条件は `cage_square.png` と同じ。

## 作業手順と制約
- 作業ブランチ: `codex/assets`（すでに作成済み。他のブランチには触らない）。
- 変更してよいのは上記3ファイルのみ。`src/` `targets/` `App.tsx` などのコードや設定は変更しない。
- 画像の生成には、あなたが使える画像生成機能を使う。使えない場合は、その旨を伝え、画像生成AI用のプロンプトを3つ出力して止まる（無理にコードで描かない）。
- `cage_square.png` と `cage_wide.png` が本当に透過になっているか、Python（Pillow）で確認する。
  - モードが RGBA であること
  - 四隅の内側（格子の間）のアルファが 0 であること
  - 檻の不透明ピクセルの割合が全体の20%以下であること
- 最後に、3枚を `assets/` に置いた状態でコミットし、確認結果（サイズ、モード、不透明率）を報告する。
- ファイル名・サイズ・形式は変えないこと。変える必要があるなら、変更せずに理由を報告する。

## 完成の目安
明るい背景に、細い金属格子の檻、その中に自分の画像がくっきり見える。ホーム画面で見て「かわいい・かっこいい・見たくなる」こと。
